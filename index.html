A code editor that feels like a native app, because it is one.

Tenmoku is written in Rust on GPUI and drawn by your GPU. It has the parts of an IDE you reach for every day, from language servers to a debugger, and no embedded web runtime.

Fast and light

Native from top to bottom: Metal on macOS, Direct3D on Windows, Vulkan on Linux. No Electron, no browser engine.

  • A 1-million-line, 33 MB file is on screen 200 ms after launch (median).
  • Scrolling holds 120 fps.
  • Idle, it uses under 1% of one CPU core.

Release build on an M3 Max MacBook Pro, from PERF.md, which says how each number is measured.

The IDE parts you use, without the weight

  • Language servers for Rust, Python, TypeScript, Go, CSS, Java, Kotlin and C# (the servers on your PATH): completion, hover, go to definition, peek, references, rename, code actions, inlay hints, format on save.
  • A debugger over the Debug Adapter Protocol: breakpoints, stepping, Variables, Watch and the call stack, for Rust, C and C++, Python, Go and Java.
  • Rust tests run from the editor, with live counts and each test's result kept.
  • Git: a log with its branch graph, line blame, a change bar in the gutter, diffs, stash and branches.
  • The project tree, find and replace across the project, a terminal, multiple cursors, sticky scroll, a minimap and Markdown preview.

Vim mode that behaves like Neovim

Motions, operators, text objects, remaps, ex commands, macros and marks. It isn't Neovim's code: it's checked against it. A corpus of cases in the repository was recorded from Neovim 0.12.4, and the tests compare Tenmoku with those recordings byte for byte: the text, the cursor, the mode, the registers and the marks.

AI agents, in their own lane

The Claude chat panel works with your own Anthropic API key. Its edits don't land in your files: they arrive as proposed changes, which you accept or reject hunk by hunk, and a turn can be reverted as a whole. The Agents panel lists each agent's lane and what it still has pending, and lines an agent wrote stay marked as its work.

69 more languages, on demand

Rust, Python, JavaScript, TypeScript, Go, C, Java, HTML, CSS, Markdown and the usual config formats are built in. Another 69, from C++, C#, Kotlin and Swift to SQL, Zig and Nix, come as WebAssembly grammars from a signed registry: the app checks the index's signature and each download's hash before it installs one.

Everywhere you work

  • macOS on Apple Silicon.
  • Windows 10 (1903 or later) and 11, on x64 and ARM64: an installer per user, no administrator rights.
  • Linux on x86_64: an AppImage or a tarball, on X11 or Wayland.

The builds aren't signed with a publisher certificate yet, so your OS warns the first time. On macOS, Gatekeeper says Apple could not verify the app: open it once, then choose Open Anyway in System Settings > Privacy & Security. On Windows, SmartScreen says it protected your PC: choose More info > Run anyway. Step by step for each platform.
